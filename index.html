IPCONFIG, PING, NETSTAT, SAMPE BISA LIAT WIFI!

0. INTERNET ITU APA? BAYANGIN KAMPUNG!

Bayangin internet itu kayak kampung gede:

- IP Address = Alamat rumah lu. Contoh: 192.168.1.5
- Router / WiFi = Gerbang kampung
- Server Google = Warung gede di kampung sebelah
- Ping = Lu teriak "HALO!" ke warung itu, terus warungnya jawab "HALO BALIK!"

CONTOH IP:
- 192.168.1.1 = Biasanya alamat Router / WiFi lu
- 192.168.1.5 = Alamat HP lu
- 8.8.8.8 = Alamat Google (DNS Google)
- 127.0.0.1 = Alamat diri sendiri (localhost) = "rumah gue sendiri"

1. ipconfig - LIAT KTP INTERNET LU (Windows)

ipconfig
ipconfig /all
FUNGSI: Liat alamat IP lu, alamat WiFi lu, dll.

- ipconfig = Liat yang penting-penting aja
- ipconfig /all = Liat SEMUA detail lengkap

YANG DICARI:
- IPv4 Address = IP HP / Laptop lu. Contoh: 192.168.1.5
- Default Gateway = IP Router WiFi lu. Contoh: 192.168.1.1
- Subnet Mask = Biasanya 255.255.255.0

2. ifconfig / ip a - VERSI LINUX / TEREMUX

ifconfig
ip a
FUNGSI: Sama kayak ipconfig, tapi buat Linux & Termux (HP Android).
- Di Termux, lu ketik ip a atau ifconfig
- Cari yang tulisannya wlan0 = itu WiFi lu

3. ping - NGETES NYAMBUNG APA ENGGAK?

ping google.com
ping 8.8.8.8
ping 192.168.1.1
ping -t google.com
FUNGSI: Ngetes apakah lu nyambung ke tempat itu, dan seberapa cepet.

- ping google.com = Teriak ke Google, dibales gak?
- ping 8.8.8.8 = Teriak ke IP Google langsung
- ping 192.168.1.1 = Teriak ke Router WiFi lu, nyambung gak?
- ping -t google.com = Teriak terus-terusan sampe lu pencet Ctrl + C (di Windows)

CARA BACA HASILNYA:
- Reply from ... time=15ms = BERHASIL! 15ms itu cepet banget! Makin kecil makin bagus.
- Request timed out = GAGAL! Gak dibales. Bisa WiFi mati, atau servernya mati.
- time=200ms = Lemot! Lagi ngelag.

ATURAN HACKER BAIK:
- Ping ke 192.168.1.1 dulu. Kalau gagal, berarti WiFi lu yang rusak.
- Kalau ke Router berhasil tapi ke google.com gagal, berarti internetnya yang mati.

4. netstat - SIAPA AJA YANG NYAMBUNG?

netstat
netstat -an
netstat -a
FUNGSI: Liat semua koneksi yang lagi jalan di komputer lu.

- netstat = Liat koneksi yang lagi aktif
- netstat -an = Liat SEMUA, pake angka IP, bukan nama
- netstat -a = Liat semua yang lagi dengerin (listening) + yang nyambung

CARA BACA:
- LISTENING = Lagi nunggu ada yang nyambung. Kayak warung lagi buka, nunggu pembeli.
- ESTABLISHED = Udah nyambung! Lagi ngobrol.
- TIME_WAIT = Baru aja putus, lagi nunggu bentar.

CONTOH: Kalau lu liat ada ESTABLISHED ke IP aneh yang lu gak kenal, itu bisa jadi ada program mencurigakan!

5. tracert / traceroute - JALUR PAKET LU LEWAT MANA?

tracert google.com
traceroute google.com
FUNGSI: Nunjukin paket internet lu lewat mana aja sampe ke Google.
- tracert google.com = di Windows
- traceroute google.com = di Linux / Termux

Contoh: Dari HP lu -> Router -> Provider -> Jakarta -> Singapura -> Google. Makin banyak lompatan, makin lama.

6. nslookup - NANYA ALAMAT IP NYA GOOGLE

nslookup google.com
nslookup youtube.com
FUNGSI: Nanya ke DNS, "Eh, alamat rumahnya google.com itu IP berapa?"
Nanti dijawab: google.com itu IP nya 142.250.x.x
DNS = Buku telepon internet. Lu ketik nama, dia kasih IP nya.

7. arp -a - LIAT SIAPA AJA DI WIFI LU!

arp -a
FUNGSI: Liat semua HP / Laptop yang lagi nyambung ke WiFi yang sama kayak lu.
Kalau lu liat ada IP yang lu gak kenal, bisa jadi ada tetangga yang numpang WiFi lu!
INGET: Cuma buat liat, jangan diusilin. Hacker baik cuma ngecek, bukan ngerusak.

8. hostname - NAMA KOMPUTER LU

hostname
hostname -I
FUNGSI:
- hostname = Nama komputer / HP lu di jaringan
- hostname -I = Langsung kasih tau IP lu aja (di Linux)

9. ipconfig /flushdns - BENERIN INTERNET NGELAG

ipconfig /flushdns
FUNGSI: Bersihin cache DNS yang udah kadaluarsa. Kadang internet ngelag karena cache nya numpuk. Abis ketik ini, internet jadi seger lagi. Ini trik teknisi warnet!
